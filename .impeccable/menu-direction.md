# DumHouse menu redesign

Confirmed by user: quiet, premium restaurant menu. Existing transactional behavior stays intact. The request authorizes replacement of the basic visual system.

Mode: Operate, with an editorial opening. Implement directly in the existing React application; the generated photograph is an illustrative asset, not a UI mockup or an approved pixel specification.

First viewport: restrained horizontal wordmark/navigation; a compact demo notice; a split opening with a finely set serif headline and an atmospheric brass-bowl biryani photograph; a compact delivery/outlet bar; a visible start to the actual menu. No ratings, awards or unverified restaurant claims.

Visual system: bone paper, deep forest ink, softened olive accents, fine dividers. Self-hosted Cormorant Garamond display and Manrope UI. One photograph owns the expressive moment. All actual interaction remains semantic HTML.

Signature interaction: selecting a menu category filters the editorial dish list; adding an item updates the persistent order summary and mobile bag dock. Customization is an inline disclosure, not a modal. Search and vegetarian filtering work together. Header bag navigation switches back to the menu and focuses the bag reliably.

Impeccable catalog references were retrieved with seed 896f76f4. The user's pinned quiet-premium choice outranks the roll. Darkroom overlays, vertical video, grid-specimen, zoo-guide, orienteering and Metro challengers were declined: each adds a visual or interaction metaphor unrelated to choosing food. Retained discipline: concise state contrast, a single focal image, precise alignment, unmistakable navigation, location context and reduced chrome, respectively. No catalog world is being claimed as a copied ready-made restaurant template.

Verification: production build; existing checkout/kitchen regression; search/filter/customization; empty and populated bag; desktop 1440px, mobile 390px, and current in-app width approximately 942px. Reduced-motion respects user preferences. Never display the photo as a photograph of an actual outlet's food.
