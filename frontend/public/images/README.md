## Light-menu category illustrations

`category-{breads,kebabs,seafood,veg,curries,rice,sweets,drinks,eggs,veg-curries}.png` were generated with the built-in ImageGen tool for this project on 2026-11-05, following the user's explicit choice to add illustrative food images. They are representative category photographs on warm ivory backgrounds, not actual restaurant photography or exact promises of ingredients/presentation. Vegetarian curry imagery is separate from meat curry imagery. Related dishes intentionally share images; the mapping is in `frontend/app/food-illustrations.json`. Original generated files are preserved under the Codex generated-images directory; copies are shipped here.

Real menu photography: `dishes/*.webp` is sourced from Wikimedia Commons contributors. Per-image creator, original source page, license and transformation details are recorded in `frontend/app/food-photos.json` and exposed at `/photo-credits.html`. Photos are representative of dishes and are not claimed to be this restaurant's own photography. Source licenses continue to apply to resized WebP versions. Earlier generated category art is retained on disk but is no longer used by the menu photo component.
